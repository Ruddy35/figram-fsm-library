# Матрица тестирования

Статусы: **PASS** — запущено, зелёное, у проверки есть отрицательный контроль, который был увиден красным;
**FAIL** — запущено, нашло дефект (см. реестры); **BLOCKED / NOT RUN** — не выполнено, с причиной.
«bin» — бинарники архива (CI-verified = официальная свежая сборка); «fresh» — локальная сборка из исходников.
