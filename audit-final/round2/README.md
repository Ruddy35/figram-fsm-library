# audit-final/round2 — второй раунд аудита Figram 0.3.0

Начните с **EXECUTIVE.md**. Судьба каждой находки — **FIXES.md**; проверки кода после раунда —
**TEST_MATRIX.md**. Первый раунд (итоговый аудит) — в родительском каталоге `audit-final/`.

| файл | содержание |
|---|---|
| EXECUTIVE.md | итог, агенты и объём проверок, что изменилось, остаточные риски |
| FIXES.md | находки трёх агентов: статус (исправлено / описано / не менялось) и коммит |
| TEST_MATRIX.md | полная локальная проверка коммита ebdfe90 (13 шагов, коды выхода, числа) и CI |
| agents/recheck/ | перепроверка исправлений первого раунда |
| agents/hostpy/ | производственный хост на Python: код хоста, внешних систем и пользователей, сценарии, журналы |
| agents/hostgo/ | встроенный хост на Go через C ABI: код хоста, привязки, сценарии, журналы |
| agents/*/REPORT.md | отчёт агента: его итоговое сообщение дословно (писать файлы агентам не разрешалось) |
| LOGS/orchestrator/ | журналы оркестратора: исправления и их контроли (`r2-fixes`), полная проверка (`v030-r2-gate`) |
| tools/ | бриф агентов (BRIEF6), `run.sh` (журналирование команд), скрипт полной проверки, `pack2.py` |
| MANIFEST.json | SHA-256 всех файлов каталога, исключённые файлы, версии, коммиты |

Журналы сделаны `tools/run.sh`: файл `*.log` = команда, каталог, время, код выхода, хвосты
вывода; рядом полные `*.stdout`/`*.stderr`. Пути внутри журналов — пути среды аудита:
`/home/user/figram-audit/agents6/X` ↔ `agents/X`, `/home/user/figram-audit/cleanup/LOGS/X` ↔
`LOGS/orchestrator/X`, `/home/user/figram-audit-worktrees/a6-X` — рабочие деревья веток
`audit6/X` (на 598fec6, без своих коммитов: агенты не меняли код продукта),
`/home/user/figram-audit-worktrees/cleanup-int` — рабочее дерево ветки
`claude/kind-ramanujan-n4q8mg`. Исключены скомпилированные бинарники и базы SQLite прогонов
(их SHA-256 — в `MANIFEST.json`; базы удалены агентом после записи сводок, кроме сценарных
прогонов). Файлы больше 3 МБ сжаты gzip.
